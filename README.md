# 첨단영상청룡토크 홈페이지

중앙대학교 첨단영상대학원 공학전공 월례 세미나의 GitHub Pages 정적 홈페이지입니다. 공개 저장소의 `docs/`를 GitHub Actions로 Pages에 게시합니다. 영상은 YouTube에 보관하며, 이 저장소에는 영상 파일을 넣지 않습니다.

## 최초 설정

1. 공개 GitHub 저장소에 이 파일들을 올립니다.
2. Settings → Pages → Build and deployment에서 Source를 **GitHub Actions**로 선택합니다. `Publish Cheongryong Talk` 작업이 사이트를 배포합니다.
3. 워크플로에 저장소 쓰기와 Pages 배포 권한이 필요합니다. 조직 정책이 이를 막으면 저장소 관리자에게 요청해야 합니다.
4. `docs/data/site.json`의 `repositoryUrl`에 저장소 주소를 입력합니다. 그러면 사이트 하단의 관리자 등록 링크가 열립니다.
5. 비공개 메일링 신청을 위해 Google Form을 만들고 응답을 비공개 Google Sheet에 연결한 뒤, `mailingFormUrl`에 **응답자용** 폼 주소를 입력합니다. 응답 시트는 공개하지 않습니다. 폼에 이메일 주소와 수신 동의 항목을 필수로 둡니다.

## 월별 세미나 등록

저장소의 Issues → New issue → **월별 청룡토크 등록** 양식을 작성합니다. 공지 내용을 입력하고 YouTube 주소는 비워 두어도 됩니다. 이슈를 제출하면 GitHub Actions가 `docs/data/talks.json`을 갱신하고 Pages에 직접 배포합니다. 영상을 나중에 올리면 같은 이슈의 **YouTube 영상 URL**만 수정합니다. 이슈 수정 후에도 자동으로 갱신됩니다.

한 달에 발표가 여러 건이면 각각 이슈를 작성합니다. 제목과 요약은 원본 공지의 사실에 맞게 입력합니다. 이슈는 공개 저장소에서 누구나 읽을 수 있으므로 비공개 자료나 이메일 명단을 넣지 않습니다. 이슈 작성자 권한이 OWNER, MEMBER, COLLABORATOR인 항목만 홈페이지 데이터에 반영됩니다. `홈페이지 표시`를 `숨김`으로 바꾸면 홈페이지 목록에서 빠지지만, 공개 이슈 자체는 남습니다.

2026년 4~9월 발표 12건은 `docs/data/history.json`에 보존합니다. **현재 공개 저장소의 이슈 동기화 스크립트는 이 기록과 병합하지 않습니다.** 새 세미나 이슈를 제출하거나 수정하면 `talks.json`에서 기존 12건이 빠질 수 있으므로, `scripts/sync_issues.py`에 준비된 병합 수정본을 반영하기 전에는 이슈를 통한 등록을 진행하지 마세요. 기존 기록을 수정할 때는 제공된 발표 목록과 대조하고, 원본 자료는 바꾸지 않습니다.

## 다음 행사 등록

첫 화면의 `예정된 토크` 영역은 `docs/data/upcoming.json`의 `events` 배열에서 날짜가 오늘(한국 시간) 이후인 일정을 보여줍니다. 사이트 하단의 **관리자 · 다음 일정 편집** 링크를 열어 다음 형식의 객체를 배열에 추가하고 GitHub에서 커밋합니다. 여러 발표가 한 행사에서 진행되면 `talks` 배열에 발표자를 계속 추가합니다. 과거 날짜의 일정은 자동으로 숨겨집니다.

```json
{
  "events": [
    {
      "date": "YYYY-MM-DD",
      "time": "HH:MM~HH:MM",
      "location": "건물·호실",
      "noticeUrl": "",
      "talks": [
        { "speaker": "발표자 이름", "affiliation": "연구실", "title": "발표 주제" }
      ]
    }
  ]
}
```

`date`는 `YYYY-MM-DD` 형식으로 입력합니다. 공지의 공개 URL이 있으면 `noticeUrl`에 넣고, 아직 없으면 빈 문자열로 둡니다. 일정이 확정되기 전에는 `events`를 빈 배열로 두면 준비 중 안내가 표시됩니다.

## 메일링리스트

이 홈페이지는 메일을 보내지 않습니다. 신청 명단은 별도의 비공개 Google Form/Sheet에서 관리하고, 월별 안내는 학교 계정의 단체메일 담당자가 발송합니다. 수신 중단은 발송 메일의 안내에 맞춰 해당 시트에서 처리합니다.

## 이미지

`docs/assets/`의 세 콘셉트 이미지는 실제 행사 기록이 아닙니다. `cau-logo-white.png`는 [중앙대학교 공식 홈페이지](https://www.cau.ac.kr/cms/FR_CON/index.do?MENU_ID=230)의 원본 워드마크 이미지입니다. 실제 발표 포스터는 해당 월별 이슈의 공개 이미지 URL로 연결할 수 있습니다. 원본 발표 자료는 이 저장소에 포함하지 않았습니다.
