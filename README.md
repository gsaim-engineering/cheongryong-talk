# 첨단영상청룡토크 홈페이지

중앙대학교 첨단영상대학원 공학전공 월례 세미나의 GitHub Pages 정적 홈페이지입니다. 공개 저장소의 `docs/`를 GitHub Actions로 Pages에 게시합니다. 영상은 YouTube에 보관하며, 이 저장소에는 영상 파일을 넣지 않습니다.

공개 주소: https://gsaim-engineering.github.io/cheongryong-talk/

## 최초 설정

1. 공개 GitHub 저장소에 이 파일들을 올립니다.
2. Settings → Pages → Build and deployment에서 Source를 **GitHub Actions**로 선택합니다. `Publish Cheongryong Talk` 작업이 사이트를 배포합니다.
3. 워크플로에 저장소 쓰기와 Pages 배포 권한이 필요합니다. 조직 정책이 이를 막으면 저장소 관리자에게 요청해야 합니다.
4. `docs/data/site.json`의 `repositoryUrl`에 저장소 주소를 입력합니다. 그러면 사이트 하단의 관리자 등록 링크가 열립니다.
5. 비공개 메일링 신청을 위해 Google Form을 만들고 응답을 비공개 Google Sheet에 연결한 뒤, `mailingFormUrl`에 **응답자용** 폼 주소를 입력합니다. 응답 시트는 공개하지 않습니다. 폼에 이메일 주소와 수신 동의 항목을 필수로 둡니다.

## 월별 세미나 등록

저장소의 Issues → New issue → **월별 청룡토크 등록** 양식을 작성합니다. **행사 날짜(YYYY-MM-DD)**, 시간, 장소, 발표자와 제목을 입력하고 YouTube 주소는 비워 두어도 됩니다. 이슈를 제출하면 GitHub Actions가 `docs/data/talks.json`을 갱신하고 Pages에 배포합니다. 영상을 나중에 올리면 같은 이슈의 **YouTube 영상 URL**만 수정합니다. 이슈 수정 후에도 자동으로 갱신됩니다.

한 달에 발표가 여러 건이면 각각 이슈를 작성합니다. 제목과 요약은 원본 공지의 사실에 맞게 입력합니다. 이슈는 공개 저장소에서 누구나 읽을 수 있으므로 비공개 자료나 이메일 명단을 넣지 않습니다. 이슈 작성자 권한이 OWNER, MEMBER, COLLABORATOR인 항목만 홈페이지 데이터에 반영됩니다. `홈페이지 표시`를 `숨김`으로 바꾸면 홈페이지 목록에서 빠지지만, 공개 이슈 자체는 남습니다.

2026년 4~9월 발표 기록 12건은 `docs/data/history.json`에 보존하며, Image Morphing 1건은 홈페이지 목록에서 숨겨 공개 목록에는 11건이 표시됩니다. 동기화 시 같은 제목·발표자의 이슈가 있어도 숨김 상태를 유지합니다. 이 수정본의 `scripts/sync_issues.py`는 기존 기록과 이슈를 병합하므로, **새 이슈를 제출하기 전에 동기화 스크립트와 이슈 양식을 함께 저장소에 반영해 주세요.** 기존 기록을 수정할 때는 제공된 발표 목록과 대조하고, 원본 자료는 바꾸지 않습니다.

## 예정된 토크와 지난 이야기

별도 입력 없이 같은 세미나 이슈가 두 영역을 오갑니다. 한국 날짜를 기준으로 **행사 당일까지는 `예정된 토크`**, **다음 날부터는 `지난 이야기`**에 표시됩니다. 방문자가 페이지를 열 때 날짜를 확인하며, 자정이 지나 페이지가 계속 열려 있어도 1분 이내에 목록을 갱신합니다. 여러 발표 이슈의 행사 날짜·시간·장소가 같으면 하나의 예정 행사 카드에 묶고, 공지 링크는 발표별로 제공합니다. 최근 발표 영역에는 이미 지난 세미나만 표시됩니다.

기존 이슈의 `일시`에 `2026. 11. 12. 17:00~18:00`처럼 날짜가 들어 있다면 그대로 읽습니다. 날짜를 알 수 없는 기록은 지난 목록에 남깁니다. 이전 버전의 `docs/data/upcoming.json`은 더 이상 읽지 않으므로 제거해도 됩니다.

## 메일링리스트

이 홈페이지는 메일을 보내지 않습니다. 신청 명단은 별도의 비공개 Google Form/Sheet에서 관리하고, 월별 안내는 학교 계정의 단체메일 담당자가 발송합니다. 수신 중단은 발송 메일의 안내에 맞춰 해당 시트에서 처리합니다.

## 이미지

`docs/assets/`의 세 콘셉트 이미지는 실제 행사 기록이 아닙니다. `cau-logo-white.png`는 [중앙대학교 공식 홈페이지](https://www.cau.ac.kr/cms/FR_CON/index.do?MENU_ID=230)의 원본 워드마크 이미지입니다. `puang-official.gif`는 제공받은 푸앙 이모티콘 GIF를 내용 변경 없이 그대로 복사한 파일입니다. 실제 발표 포스터는 해당 월별 이슈의 공개 이미지 URL로 연결할 수 있습니다. 원본 발표 자료는 이 저장소에 포함하지 않았습니다.
